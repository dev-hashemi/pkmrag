# Hybrid Retrieval Architecture

Combining keyword-based lexical recall with dense semantic representations.

## Core Formula
Uses [[Reciprocal Rank Fusion#Score Normalization|Reciprocal Rank Fusion]] to blend results:
- Dense: [[Vector Retrieval]]
- Sparse: [[Lexical BM25]]

Essential retrieval tier for [[Orbit Core]].
